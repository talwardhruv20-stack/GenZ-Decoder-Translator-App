# 😎 Gen-Z Decoder + Translator App

A full-stack Python web application built with **Streamlit** that bridges the gap between traditional languages, standard English, and modern internet/Gen-Z culture. Featuring a custom dark theme UI, live translation capabilities, a slang generator, and an offline-first fallback architecture for seamless live demonstrations.

## 🚀 Live Demo
🔗 **App URL:** (https://genz-decoder-translator-app-gf6rwcobexjmht7gsp5x8n.streamlit.app/)


## ✨ Key Features

* **🌐 Language Translator:** Translate standard English phrases into multiple languages (Hindi, Punjabi, Spanish, French, German, Japanese) with built-in rate-limit protection.
* **😎 Gen-Z Slang Decoder:** Break down modern internet slang and abbreviations into clear, plain English.
* **⚡ Gen-Z Slang Generator:** Transform standard text into trendy Gen-Z lingo with adjustable vibe intensity levels (*Subtle*, *Casual Gen-Z*, *Chronically Online*).
* **📖 Slang Dictionary:** Searchable dictionary of popular internet terms, complete with definitions and real-world usage examples.
* **🕒 Activity History:** Real-time tracking of recent lookups filtered across different app modules, powered by Pandas.
* **🛡️ Offline-First Fallback Engine:** Engineered with robust local dictionaries to guarantee zero-downtime performance during live presentations, bypassing public API rate limits.

---

## 🛠️ Tech Stack

* **Frontend & Framework:** Streamlit (Python)
* **Styling:** Custom CSS (Dark Theme GitHub-inspired UI)
* **Data Manipulation:** Pandas
* **Translation Engine:** `deep-translator` & Custom Fallback Logic
